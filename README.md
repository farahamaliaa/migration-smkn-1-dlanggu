cara set up:
1. clone repository ini
2. buka di teks editor (vscode/antigravity/cursor/dsb.)
3. buka terminal teks editor
4. jalankan perintah => composer update
5. jalankan perintah => cp .env.example .env
6. jalankan perintah => php artisan migrate
7. tunggu hingga proses selesai, lalu cek di phpMyAdmin di laptop kalian masing-masing
